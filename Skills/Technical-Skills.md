# Technical Skills

## Technical Development, Data Analysis Tools & Business Intelligence Capabilities

### Purpose

This document outlines the technical knowledge, software tools, programming concepts, and analytical capabilities I am developing to support my transition from accounting and financial operations into Business Analytics, Financial Analytics, Data Analytics, Business Intelligence, and related disciplines.

My professional background includes more than 20 years of experience in accounting and financial operations, including accounts receivable, accounts payable, bookkeeping, reconciliations, cash applications, and enterprise business systems.

## 7. Tool Selection by Business Problem

Different tools are appropriate for different analytical needs.

| Business Problem | Potential Tool | Reason |
|---|---|---|
| Calculate invoice aging | Excel or Python | Supports date-based calculations |
| Summarize sales by product | Excel, SQL, or Power BI | Supports aggregation |
| Clean inconsistent data | Excel Power Query or Python | Supports repeatable transformations |
| Retrieve records from a database | SQL | Designed for querying structured data |
| Develop interactive KPI reports | Excel or Power BI | Supports visual reporting |
| Automate repetitive calculations | Python | Supports reusable programming logic |
| Analyze financial trends | Excel, SQL, Python, or Power BI | Tool depends on dataset and reporting needs |
| Compare budgets with actual results | Excel or Power BI | Supports variance reporting |
| Build a financial forecast | Excel or Python | Supports modeling and scenarios |
| Present executive business insights | Excel or Power BI | Supports accessible reporting |

**Tool Selection Principle:** Choose software based on the business question, available data, required analysis, and intended audience.
