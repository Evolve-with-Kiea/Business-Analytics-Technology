## Skill Level Scale

I use one scale throughout the repository so that claims stay consistent.

| Level | Meaning |
|---|---|
| Planned | I intend to learn this but have not started. |
| Learning | I am studying this and can explain basic concepts. |
| Practicing | I can complete guided exercises and am working toward independent practice. |
| Applied | I have used this skill independently on a project and can link to evidence. |

I do not describe a skill as "proficient" or "advanced" unless I can support it with documented work and, where relevant, an assessment or credential.
