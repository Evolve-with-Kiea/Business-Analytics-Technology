# Course Notes

This folder holds my notes for each course. Notes are written in my own words to deepen understanding and to create a reference I can reuse.

## Organization

Create one Markdown file per course or per topic, using a consistent name.

```text
Course-Notes/
├── README.md
├── BAS-120-Notes.md
└── BAS-150-Notes.md
```

Files can be added as courses begin. Use hyphens instead of spaces in filenames.

## Note Template

```markdown
# [Course code]: [Topic]

## Key Concepts
- Concept and plain-English explanation

## Why It Matters
- Business relevance

## Example
- A worked example or scenario

## Questions
- Items I still need to clarify
```

## Guidelines

- Write notes in my own words. Do not paste copyrighted course materials, slides, or textbook passages.
- Do not publish exam questions, graded assignments, or content my institution restricts.
- Do not include private information about instructors or classmates.
- Link notes to related entries in the [Coursework Tracker](../Coursework-Tracker.md).
