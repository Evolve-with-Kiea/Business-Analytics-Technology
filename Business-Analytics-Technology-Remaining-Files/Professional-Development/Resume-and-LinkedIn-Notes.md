# Resume and LinkedIn Notes

## Purpose

This document holds my guidelines and drafting notes for resume and LinkedIn content. It does not contain employment history, degrees, or accomplishments, because those must be entered only from verified records.

## Accuracy Rules

- Include only experience, education, and credentials I can document.
- Describe skills at the level I can support. Use the scale in [Skills Evidence](../Skills/Skills-Evidence.md).
- State accomplishments with numbers only when I can explain how they were measured.
- Do not describe a tool as a strength if I am still learning it. Use wording such as "developing skills in" or "currently learning."

## Resume Planning

**Possible sections**

| Section | What belongs | Status |
|---|---|---|
| Header and contact information | Name, location, email, LinkedIn, GitHub repository link | [ ] |
| Summary | Two or three sentences based on my [Professional Statement](../About/Professional-Statement.md) | [ ] |
| Education | Verified institution, program, and dates | [ ] |
| Skills | Tools I can support with evidence, grouped by category | [ ] |
| Projects | Documented projects with the business question and tools used | [ ] |
| Certifications | Only credentials listed in [Certifications Earned](../Certifications/Certifications-Earned.md) | [ ] |
| Experience | Verified work or volunteer experience, with factual descriptions | [ ] |

**Project bullet structure**

> Action verb + what I analyzed or built + tool or method + result or purpose

Use real details only. Add a measurable result only when it exists.

## LinkedIn Planning

| Element | Guidance |
|---|---|
| Headline | Describe my direction and focus accurately, such as the areas I am studying |
| About section | Adapt my professional statement in first person |
| Featured section | Link to this repository and finished projects |
| Skills | Add skills I can support; avoid listing tools I have not used |
| Education | List verified education and planned coursework only as appropriate |
| Licenses and certifications | Add only earned credentials, with verification links |
| Activity | Share what I am learning, with business context |
