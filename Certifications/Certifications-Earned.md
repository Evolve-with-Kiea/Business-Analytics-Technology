## Credential Categories

| Category | Description |
|---|---|
| Course | Structured learning without necessarily awarding a formal credential |
| Completion Certificate | Recognition for completing specified training |
| Professional Certificate | A structured educational program, often involving multiple courses or assessments |
| Industry-Recognized Certification | A credential typically awarded after meeting examination or assessment requirements |
| Vendor Certification | A credential issued by a technology or software provider |
| Professional License | A legally regulated qualification issued by an authorized licensing body |

Credential categories will be recorded accurately rather than treating all learning achievements as equivalent certifications.

## Credential Documentation Standards

For each completed credential, I will record:

- Official credential name
- Issuing organization
- Credential category
- Date earned
- Expiration or renewal requirements, if applicable
- Credential ID, if issued
- Public verification link, if available
- Skills and knowledge covered
- Professional relevance
- Related practical projects or applications

A credential will not be represented as current if its validity has expired.
