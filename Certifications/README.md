## Types of Learning Credentials

Not all credentials carry the same weight. I use these categories consistently.

| Category | Description | Typical example |
|---|---|---|
| Course | A learning experience with no formal credential or with only a basic completion notice | A self-paced lesson series |
| Course completion certificate | A document confirming that I finished a course or learning path; usually not an exam of independent skill | freeCodeCamp or HubSpot Academy course certificates |
| Professional certificate | A multi-course program from a provider or platform, often with a capstone or assessments | Professional certificate programs on Coursera |
| Industry-recognized certification | An exam-based credential issued by a vendor or professional body with defined standards | Microsoft, IIBA, PMI, and Python Institute certifications |

## Principles

- **Accuracy.** I record a credential as earned only after I have completed it.
- **Clarity.** I describe each credential by its true category.
- **Relevance.** I pursue credentials that match my learning goals, not only those that sound impressive.
- **Verification.** I check fees, requirements, and exam details on the provider's official page before committing.
